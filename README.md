## 🌟 Executive Overview

**Ultimate Secret Messenger** is an all-in-one cryptographic workspace, forensic steganography laboratory, encrypted real-time chat system, university-level cybersecurity academy, and competitive logic arcade built with Python and Streamlit.

### 🚀 Core Architecture (8 Integrated Modules + AI Mentor + Game Arcade)

1. **🏠 1. Home Dashboard & Live Agent Command Center (`core/command_center.py`):**
   - Real-time telemetry across all platform databases with **24/7 Google Firebase Realtime Database Auto-Sync**.
   - Dynamic **PIL Credential Engine** that renders downloadable **Agent Cyber ID Cards (`.PNG`)** and **Official Graduation Certificates (`.PNG`)** signed with `SHA-256` verification hashes.
2. **🔐 2. Cipher Workspace & Multi-Layer Steganography (`core/multimedia_crypto.py`):**
   - Custom 229-character Unicode Key Permutation, UTC Time-Locked Encryption, English Cover-Text Camouflage, Lossless `.PNG` LSB Image Steganography, and 16-bit `.WAV` Audio Steganography.
3. **💬 3. Secret Chat Rooms (`core/messenger_chat.py`):**
   - Persistent encrypted group rooms (`#3001`) plus a full-featured **1-on-1 & Group Messenger** supporting friend requests, voice notes, stickers, image attachments, and message reactions.
4. **🕹️ 4. Crypto Challenges — 5-Tier CTF Arena (`core/command_center.py`):**
   - 28 progressive Capture-The-Flag challenges with interactive **SQL Injection (SQLi)** and **JSON Web Token (JWT)** exploit sandboxes.
5. **📚 5. Security Academy — 30-Module University Curriculum:**
   - **Track 1 (Modules 01–03):** Classical Cryptography & Frequency Cryptanalysis.
   - **Track 2 (Modules 04–09):** Low-Level Computer Systems (Bits, Bytes, Two's Complement, Bitwise Ops, Little-Endian & x86-64 Assembly).
   - **Track 3 (Modules 10–13):** Number Theory, Modular Arithmetic & Shannon's Perfect Secrecy.
   - **Track 4 (Modules 14–20):** Modern & Post-Quantum Cryptography (SHA-256, AES-256, RSA, Forensics & Lattice PQC).
   - **Track 5 (Modules 21–26):** Character Encoding (`UTF-8`, `ASCII`), Binary-to-Text (`Base64`, `URL %20`, `HTML XSS`), Multimedia Codecs (`H.265`, `FLAC`), ML Categorical Encoding (`One-Hot`, `Target`), `SQL Injection` & `JWT`.
   - **Track 6 (Modules 27–30):** `TLS 1.3 & PKI`, `Elliptic Curve Cryptography (ECC)`, `Zero-Knowledge Proofs (ZKP)` & `Fully Homomorphic Encryption (FHE)`.
6. **🤖 Multilingual AI Cyber Mentor v4.0 (`core/ai_cyber_mentor.py`):**
   - Automatic 100+ language translation bridge, live bitwise/cipher computation, forensic file/image byte scanner, autonomous Wikipedia knowledge harvester, and Admin-locked training studio.
